Introduction

Source hosts identify the Microsoft SQL Server instances that Data Sync reads from. This includes Azure SQL, Azure SQL Managed Instance, and on-premises Microsoft SQL Server.

To get started, select the Data Sync menu and choose Source Host Configuration:

Source Host list

The list shows registered source hosts, including the instance name and whether the host is active.

Use Refresh to reload the list. Use the row Edit action to change an existing source host.

Add a source host

Select Add Source Host to open the edit dialog.

Fields:

  • Instance Name - the SQLPro instance (client) to use as the source. Required. Locked after the host is created.
  • Is Active - when off, the host is unavailable for new sync configurations and in all the monitoring screens.

Select Save to create or update the host, or Cancel to discard changes.

Note

Source hosts are always Microsoft SQL Server (Azure SQL, Azure SQL Managed Instance, or on-premises). Fabric instances cannot be used as sources.

Tip

Register the instance under Administration > Instances before adding it as a source host. Microsoft SQL Server instances can use Windows Authentication, SQL Server Authentication, Microsoft Entra Password, or Microsoft Entra Service Principal.
