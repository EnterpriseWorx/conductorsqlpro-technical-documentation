Introduction

Live Alerts monitor registered instances for operational issues and surface them in a live report, with optional email notifications.

Live Alerts can run against supported instance types. Availability of individual built-in alerts depends on the platform — for example, SQL Agent, SQL Server Jobs, and replication alerts apply to Microsoft SQL Server only.

To reach the live alerts section select the Live Alert Icon:

The live alert menu offers the following options:

  • Live Report - view current alerts and alert history.
  • Edit Live Alerts - enable, disable, and configure standard or custom live alerts.
  • System Settings - configure schedules and system options for live alerts.
