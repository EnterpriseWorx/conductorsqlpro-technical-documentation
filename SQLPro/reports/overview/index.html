Introduction

Reports provides visibility into the health, structure, and activity of your SQL Server environment. Use it to review instance health checks, track structural changes across servers, and generate an environment-wide audit summary.

To reach the reports section, select the Reports icon:

Note

The Reports menu is available when your role includes ReportView and/or AuditView. Individual reports are shown or hidden based on those permissions.

The Reports menu offers the following options:

  • SQL Environment Audit History Report - generate a detailed Microsoft SQL Server environment audit covering instance inventory, licensing and core counts, database backup and CheckDB status, governance checks, and recommendations.
  • Audit History Report (Server Activity Audit History Report) - review database structural changes across your environment, such as logins, tables, views, and indexes being added, modified, or removed. You can also configure email alerts for selected events.
  • Health Report - run communication, database, job, and security health checks against your SQL Server instances.

Tip

Server Activity Audit must be enabled on each Microsoft SQL Server instance you want to track. Open Administration >> Instances, edit the instance, and turn on the audit option. This feature is available for Microsoft SQL Server, not Azure SQL or other database types.
