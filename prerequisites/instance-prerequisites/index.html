Supported instance types

Supported features depend on the instance type you add to Conductor4SQL.

Currently supported instance types:

  • Microsoft SQL Server
  • Microsoft Azure SQL
  • Microsoft Azure SQL Managed Instance
  • Microsoft Fabric Data Warehouse
  • MySQL
  • PostgreSQL

For hardware and software requirements of the central Conductor4SQL server, see Central Node Prerequisites. For Data Sync source and target requirements (Change Tracking, primary keys, Blob SAS), see Data Sync Getting Started.
