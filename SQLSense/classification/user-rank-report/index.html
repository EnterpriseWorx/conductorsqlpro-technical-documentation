Introduction

The User Rank Report shows which users have the most access to sensitive data, based on verified classification results. Use it to prioritise access reviews and compliance follow-up.

To open the report, select the Classification icon, then User Rank Report:

The report lists users with recent activity and how much sensitive data they can access.
