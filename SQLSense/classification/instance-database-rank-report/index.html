Introduction

The Instance Database Rank Report shows how much sensitive data each instance or database contains, based on verified classification columns. Use it to compare exposure across environments and drill into who has access.

To open the report, select the Classification icon, then Instance Database Rank Report:

The main view ranks instances and databases by the amount of sensitive data flagged.

From a ranked row you can open access details to see which users can reach those columns.
